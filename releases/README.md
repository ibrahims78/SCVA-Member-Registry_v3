## 🚀 تثبيت التطبيق على Windows

### الخطوات:

1. **فك ضغط الأرشيف** `SCVA-Members-v1.0.0-Windows-x64.tar.gz`  
   استخدم برنامجاً مثل [7-Zip](https://www.7-zip.org/) أو WinRAR

2. **افتح المجلد** `SCVA Members-win32-x64`

3. **شغّل التطبيق** بالنقر المزدوج على `SCVA Members.exe`

> **ملاحظة:** قد يُظهر Windows تحذيراً (SmartScreen) لأن التطبيق غير موقَّع رقمياً.  
> اضغط **"معلومات إضافية"** ثم **"تشغيل على أي حال"** للمتابعة.

---

## 🔑 أول تشغيل

عند فتح التطبيق لأول مرة:

1. **ستظهر كلمة المرور الأولية** في نافذة الطرفية (Terminal) التي تفتح مع التطبيق
2. **بيانات الدخول:**
   - اسم المستخدم: `admin`
   - كلمة المرور: تُطبع مرة واحدة في السجل عند أول تشغيل
3. سيطلب منك التطبيق **تغيير كلمة المرور** فور الدخول الأول
4. بعد التغيير — أنت جاهز!

## 🐛 حل المشكلات

**التطبيق لا يفتح:**
- تأكد أن نظامك 64-bit (لا يعمل على 32-bit)
- جرّب تشغيل `SCVA Members.exe` كمسؤول (Run as Administrator)
- تأكد من أن مضاد الفيروسات لا يحجب التطبيق

**لا تظهر كلمة المرور الأولية:**
- انظر إلى نافذة الطرفية (cmd) التي تفتح مع التطبيق
- إذا لم تجدها، احذف ملف قاعدة البيانات (أو انقله) وأعد تشغيل التطبيق

**بطء عند أول تشغيل:**
- طبيعي — التطبيق يُهيّئ قاعدة البيانات وخادم الواجهة محلياً

**لا يمكن فتح الملف (خطأ Windows Defender):**
- افتح Windows Security
- اذهب إلى Virus & Threat Protection
- أضف مجلد التطبيق كاستثناء

## 🏗️ إعادة البناء من المصدر (للمطورين)

إذا أردت بناء التطبيق بنفسك من المصدر:

```bash

git clone <repo>
cd desktop
npm install
cd ..
npm install
cd desktop
node build.js
```

أو على Windows، شغّل `build-windows.bat` مباشرة.
