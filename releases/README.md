## 🚀 تثبيت التطبيق على Windows

### الخطوات:

1. **فك ضغط الأرشيف** باستخدام [7-Zip](https://www.7-zip.org/) أو WinRAR أو الضغط على "استخراج الكل" في ويندوز

2. **افتح المجلد** `SCVA Members-win32-x64`

3. **شغّل التطبيق** بالنقر المزدوج على `SCVA Members.exe`

> **ملاحظة:** قد يُظهر Windows تحذيراً (SmartScreen) لأن التطبيق غير موقَّع رقمياً.  
> اضغط **"معلومات إضافية"** ثم **"تشغيل على أي حال"** للمتابعة.

## 🆕 ما الجديد في الإصدار 1.3.0

### 🐛 إصلاح جذري: محرك قاعدة البيانات لا يبدأ (WASM مفقود)

**المشكلة:** كانت النسخ السابقة تعتمد على آلية `--asar-unpack` وحدها لاستخراج ملف `sql-wasm.wasm` (محرك SQLite) خارج أرشيف الـ `.asar`. في حالات معينة أثناء التحزيم، لم يكن الملف يُستخرج بشكل صحيح، مما يؤدي إلى:
- فشل كامل في تشغيل محرك قاعدة البيانات
- عدم استجابة جميع نقاط API
- فقدان كامل للبيانات عند إغلاق التطبيق

**الإصلاح:** إضافة خطوة نسخ يدوي صريح في سكريبت البناء تضمن وجود الملف في المسار الصحيح دائماً بشكل مستقل عن أي آلية تحزيم:
```
resources\app.asar.unpacked\node_modules\sql.js\dist\sql-wasm.wasm
```
التحقق من وجود الملف بعد البناء وإيقاف العملية فوراً إذا كان مفقوداً.

## 🆕 ما الجديد في الإصدار 1.2.0

### 🐛 إصلاح حرج: اختفاء البيانات بعد إعادة التشغيل

**المشكلة:** على Windows، عملية `fs.renameSync` كانت تفشل بصمت بخطأ `EPERM` في حالات معينة (مثل: فحص Windows Defender للملف). النتيجة: البيانات تبقى في الذاكرة فقط وتضيع عند الإغلاق.

**الإصلاح:** آلية حفظ ذات 3 مستويات:
1. الكتابة الذرية (temp → rename)
2. إذا فشلت → كتابة مباشرة للملف الهدف
3. إذا فشل كل شيء → كتابة مباشرة بدون ملف مؤقت

### ⚡ تحسين الحفظ التلقائي
- الحفظ التلقائي كل **5 ثوانٍ** (كان 15 ثانية)

## 🐛 حل المشكلات

**التطبيق لا يفتح:**
- تأكد أن نظامك 64-bit (لا يعمل على 32-bit)
- جرّب تشغيل `SCVA Members.exe` كمسؤول (Run as Administrator)
- تأكد من أن مضاد الفيروسات لا يحجب التطبيق

**لا تظهر كلمة المرور الأولية:**
- انظر إلى نافذة الطرفية (cmd) التي تفتح مع التطبيق
- إذا لم تجدها، احذف ملف قاعدة البيانات (أو انقله) وأعد تشغيل التطبيق

**بطء عند أول تشغيل:**
- طبيعي — التطبيق يُهيّئ قاعدة البيانات وخادم الواجهة محلياً

**لا يمكن فتح الملف (خطأ Windows Defender):**
- افتح Windows Security → Virus & Threat Protection
- أضف مجلد التطبيق كاستثناء
