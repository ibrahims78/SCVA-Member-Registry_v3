## 📁 أين تُحفظ البيانات على Windows؟

### موقع قاعدة البيانات الرئيسية

```
C:\Users\[اسم المستخدم]\AppData\Roaming\SCVA Members\scva-members.db
```

**مثال على مستخدم اسمه Ahmad:**
```
C:\Users\Ahmad\AppData\Roaming\SCVA Members\scva-members.db
```

> **ملاحظة:** مجلد `AppData` مخفيٌّ افتراضياً في Windows.  
> لإظهاره: افتح File Explorer ← View ← تأكد من تفعيل **Hidden items**

### الوصول السريع
افتح موجه الأوامر (CMD) وأدخل:
```
explorer %APPDATA%\SCVA Members
```
سيفتح المجلد مباشرةً في File Explorer.

### ملفات إضافية في نفس المجلد

| الملف | الوصف |
|---|---|
| `scva-members.db` | قاعدة البيانات الرئيسية (SQLite) |
| `scva-members.db.tmp` | ملف مؤقت أثناء الحفظ (يُحذف تلقائياً) |

## 🗄️ شرح قاعدة البيانات SQLite المستخدمة

### ما هي SQLite؟

SQLite هي قاعدة بيانات **مضمَّنة داخل التطبيق** — لا تحتاج إلى خادم منفصل (كـ MySQL أو PostgreSQL).
كل البيانات تُخزَّن في **ملف واحد** على القرص الصلب هو `scva-members.db`.

### كيف يستخدمها التطبيق؟

التطبيق يستخدم مكتبة **sql.js** وهي نسخة من SQLite مُترجَمة إلى WebAssembly (WASM).
هذا يعني:
- لا يحتاج تثبيت أي برنامج إضافي على جهازك
- تعمل على أي جهاز Windows بدون إعداد مسبق
- البيانات محفوظة محلياً — لا ترسَل لأي خادم خارجي

### جداول قاعدة البيانات

| الجدول | الوصف |
|---|---|
| `users` | حسابات المستخدمين (اسم، كلمة مرور مشفَّرة، دور) |
| `members` | بيانات الأعضاء (الاسم، التخصص، رقم العضوية...) |
| `subscriptions` | الاشتراكات السنوية لكل عضو |
| `activity_log` | سجل جميع العمليات على النظام |

### آلية الحفظ

- **كل عملية كتابة** (إضافة/تعديل/حذف) تُحفظ **فوراً** على القرص
- **حفظ تلقائي** إضافي كل **15 ثانية** كشبكة أمان
- **حفظ عند الإغلاق**: يتم حفظ نهائي تلقائياً عند إغلاق التطبيق
- **كتابة ذرية**: يكتب إلى ملف مؤقت أولاً ثم يُعيد تسميته — يمنع تلف البيانات عند انقطاع الكهرباء

```cmd
:: نقل قاعدة البيانات القديمة إلى مكان آخر (للحفاظ عليها)
```

3. اضغط أيقونة **تعديل** (✏️) بجانب حساب المدير
4. أدخل كلمة المرور الجديدة في حقل "كلمة مرور جديدة"
5. اضغط **تحديث**

## 📋 سجل الأحداث (Activity Log)

### عرض السجل من داخل التطبيق

1. اذهب إلى **الإعدادات ← سجل الأحداث**
2. استخدم خانة **البحث** لتصفية الأحداث بالاسم أو الإجراء
3. اضغط **تصدير Excel** لتحميل السجل كملف Excel
4. اضغط **نسخ** لنسخ السجل إلى الحافظة

### مسح السجل

1. اذهب إلى **الإعدادات ← سجل الأحداث**
2. اضغط **مسح السجل** (زر أحمر في أعلى يمين الجدول)
3. أكّد الإجراء في مربع التأكيد

> ⚠️ مسح السجل لا يُؤثر على بيانات الأعضاء أو الاشتراكات.

### عرض السجل مباشرةً في قاعدة البيانات (للمطورين)

استخدم [DB Browser for SQLite](https://sqlitebrowser.org/) وافتح ملف `scva-members.db`، ثم انتقل إلى جدول `activity_log`.

## 🗃️ أوامر قاعدة البيانات SQLite (للمطورين)

### الأداة الموصى بها: DB Browser for SQLite

تحميل مجاني من: https://sqlitebrowser.org/dl/

افتح ملف `scva-members.db` من المسار:
```
C:\Users\[اسم المستخدم]\AppData\Roaming\SCVA Members\scva-members.db
```

### أوامر SQL مفيدة (عبر DB Browser أو sqlite3.exe)

```sql
-- عرض جميع الأعضاء
SELECT id, first_name, last_name, membership_number, specialty 
FROM members 
ORDER BY membership_number;

-- عرض أعضاء تخصص معين
SELECT first_name, last_name, email, phone 
FROM members 
WHERE specialty = 'cardiology';

-- عدد الأعضاء الكلي
SELECT COUNT(*) AS total_members FROM members;

-- عرض الاشتراكات مع أسماء الأعضاء
SELECT m.first_name, m.last_name, s.year, s.amount, s.date
FROM subscriptions s
JOIN members m ON s.member_id = m.id
ORDER BY s.year DESC, m.last_name;

-- مجموع الاشتراكات لكل سنة
SELECT year, COUNT(*) AS count, SUM(amount) AS total
FROM subscriptions
GROUP BY year
ORDER BY year DESC;

-- عرض آخر 20 حدث في السجل
SELECT timestamp, username, action, details
FROM activity_log
ORDER BY timestamp DESC
LIMIT 20;

-- البحث عن عضو بالاسم
SELECT * FROM members 
WHERE first_name LIKE '%محمد%' OR last_name LIKE '%محمد%';

-- عرض الأعضاء بدون اشتراك لسنة محددة
SELECT m.first_name, m.last_name, m.membership_number
FROM members m
WHERE m.id NOT IN (
    SELECT member_id FROM subscriptions WHERE year = 2024
)
ORDER BY m.membership_number;

-- عرض كل مستخدمي النظام (بدون كلمات المرور)
SELECT id, username, role, must_change_password 
FROM users;

-- حذف سجلات الأحداث الأقدم من 6 أشهر (احذر!)
DELETE FROM activity_log 
WHERE timestamp < datetime('now', '-6 months');

-- عدد جداول قاعدة البيانات
SELECT name FROM sqlite_master WHERE type='table';
```

### تصدير قاعدة البيانات كاملةً إلى SQL نصي

```cmd
:: إذا كان لديك sqlite3.exe (يمكن تحميله من https://sqlite.org/download.html)
sqlite3 "%APPDATA%\SCVA Members\scva-members.db" .dump > scva-full-export.sql
```

### إنشاء نسخة احتياطية يدوية

```cmd
:: نسخ ملف قاعدة البيانات مباشرةً
copy "%APPDATA%\SCVA Members\scva-members.db" "%USERPROFILE%\Desktop\scva-backup-%date:~-4,4%%date:~-7,2%%date:~-10,2%.db"
```

## 💾 النسخ الاحتياطي والاستعادة

### نسخ احتياطي من داخل التطبيق (موصى به)

1. اذهب إلى **الإعدادات ← البيانات**
2. اضغط **تصدير نسخة احتياطية**
3. احفظ الملف `.json` في مكان آمن

### استعادة من نسخة احتياطية (جديد في v1.1.0)

1. اذهب إلى **الإعدادات ← البيانات**
2. اضغط **اختيار ملف النسخة الاحتياطية (.json)**
3. اختر ملف `.json` المحفوظ مسبقاً
4. البيانات ستُضاف للموجودة (لن يُحذف أي شيء)

### مسح جميع البيانات والبدء من جديد (جديد في v1.1.0)

1. اذهب إلى **الإعدادات ← البيانات**
2. اضغط **مسح جميع البيانات والعودة للبداية**
3. أكّد في مربع التأكيد
4. جميع الأعضاء والاشتراكات وسجل الأحداث ستُحذف (حسابات المستخدمين تبقى)

## 🌐 واجهة برمجة التطبيقات (API) — للمطورين

التطبيق يُشغّل خادم HTTP داخلياً على المنفذ `43210`.
يمكن الوصول إليه من المتصفح أو من أدوات مثل curl أو Postman أثناء تشغيل التطبيق.

```
http://127.0.0.1:43210
```

### أمثلة على طلبات API (تتطلب تسجيل الدخول أولاً)

```bash
# تسجيل الدخول
curl -c cookies.txt -X POST http://127.0.0.1:43210/api/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"admin\",\"password\":\"كلمة_المرور\"}"

# جلب قائمة الأعضاء
curl -b cookies.txt http://127.0.0.1:43210/api/members

# تصدير نسخة احتياطية
curl -b cookies.txt http://127.0.0.1:43210/api/backup -o backup.json

# عرض سجل الأحداث
curl -b cookies.txt http://127.0.0.1:43210/api/activity-log

# مسح جميع البيانات (admin فقط)
curl -b cookies.txt -X POST http://127.0.0.1:43210/api/reset \
  -H "Content-Type: application/json" -d "{}"
```

## 🔧 حل المشكلات الشائعة

### التطبيق لا يحفظ البيانات

1. تأكد من أن Windows لا يمنع الكتابة إلى `%APPDATA%`
2. تأكد من أن مضاد الفيروسات لا يحجب `scva-members.db`
3. شغّل التطبيق **كمسؤول** (Run as Administrator)
4. تحقق من أن لديك مساحة كافية على القرص

### رسالة "Database not initialized"

يعني أن ملف WASM لم يُعثر عليه. الحل:
1. تأكد من أن مجلد التطبيق غير منقوص (فك الضغط بالكامل)
2. تأكد من أن مضاد الفيروسات لم يحذف `sql-wasm.wasm` من مجلد `resources\app.asar.unpacked\`

### نسيان كلمة مرور المدير

1. أوقف التطبيق
2. افتح `scva-members.db` ببرنامج [DB Browser for SQLite](https://sqlitebrowser.org/)
3. انتقل إلى جدول `users`
4. احذف صف المدير (admin)
5. احفظ وأغلق DB Browser
6. شغّل التطبيق — سيُنشئ admin جديداً بكلمة مرور جديدة تظهر في نافذة CMD

## 🗑️ ماذا يحدث إذا حذفت ملف scva-members.db؟

عند إعادة تشغيل التطبيق بعد الحذف يحدث التالي:

**1. يُنشئ التطبيق قاعدة بيانات جديدة فارغة تلقائياً**
— نفس المسار، نفس الاسم، لكن فارغة تماماً.

**2. يُنشئ مستخدم `admin` جديد بكلمة مرور عشوائية جديدة**
— تظهر في نافذة CMD مرة واحدة فقط عند أول تشغيل.

**3. كل البيانات التالية تُفقَد نهائياً:**
- ❌ جميع بيانات الأعضاء
- ❌ جميع الاشتراكات السنوية
- ❌ سجل الأحداث
- ❌ جميع حسابات المستخدمين (بما فيها كلمات المرور المُغيَّرة)

> ⚠️ الحذف **لا عودة منه** — لا يوجد سلة محذوفات لقواعد البيانات.  
> يُنصح دائماً بـ**نقل** الملف إلى مكان آخر بدلاً من حذفه، لإبقاء إمكانية الاسترجاع.

### الحماية من هذا السيناريو

اعمل نسخاً احتياطية منتظمة من داخل التطبيق:
> الإعدادات ← البيانات ← **تصدير نسخة احتياطية** (ملف JSON)

أو انسخ الملف يدوياً:
```cmd
copy "%APPDATA%\SCVA Members\scva-members.db" "D:\Backup\scva-backup.db"
```

## 💻 نقل التطبيق إلى جهاز جديد

**نعم، يعمل تماماً** — هذه إحدى أهم مزايا SQLite. كل البيانات في ملف واحد قابل للنقل.

### الطريقة الأولى: نقل ملف قاعدة البيانات مباشرةً (تنقل كل شيء)

**على الجهاز القديم — انسخ الملف:**
```
C:\Users\[اسم_قديم]\AppData\Roaming\SCVA Members\scva-members.db
```

**على الجهاز الجديد — ضع الملف في:**
```
C:\Users\[اسم_جديد]\AppData\Roaming\SCVA Members\scva-members.db
```
> إذا لم يكن مجلد `SCVA Members` موجوداً، أنشئه يدوياً.

ثم شغّل التطبيق — سيجد الملف ويحمّل كل البيانات مباشرةً.

### ما الذي ينتقل معك؟

| البيانات | الحالة |
|---|---|
| جميع بيانات الأعضاء | ✅ تنتقل كاملةً |
| الاشتراكات السنوية | ✅ تنتقل كاملةً |
| حسابات المستخدمين وكلمات المرور | ✅ تنتقل كاملةً |
| سجل الأحداث | ✅ ينتقل كاملاً |

### الطريقة الثانية: عبر النسخ الاحتياطي JSON (لا تنقل كلمات المرور)

**على الجهاز القديم:**
> الإعدادات ← البيانات ← **تصدير نسخة احتياطية** → احفظ ملف `.json`

**على الجهاز الجديد (بعد تشغيل التطبيق وتسجيل الدخول):**
> الإعدادات ← البيانات ← **استيراد من نسخة احتياطية** → اختر ملف `.json`

> ملاحظة: هذه الطريقة تنقل الأعضاء والاشتراكات فقط — **لا تنقل كلمات مرور المستخدمين** لأسباب أمنية.

## 📂 تغيير موقع قاعدة البيانات (مثلاً إلى D:)

مفيد إذا أردت أن يشارك **جميع مستخدمي الجهاز** نفس قاعدة البيانات.

### الخطوات

**1. أنشئ المجلد على D:**
```cmd
mkdir "D:\SCVA-Data"
```

**2. انقل الملف الموجود إلى المسار الجديد:**
```cmd
move "%APPDATA%\SCVA Members\scva-members.db" "D:\SCVA-Data\scva-members.db"
```

**3. اضبط متغير البيئة على مستوى النظام كله**

افتح موجه الأوامر **كمسؤول** (Run as Administrator):
```cmd
setx SQLITE_DB_PATH "D:\SCVA-Data\scva-members.db" /M
```
> الخيار `/M` يضبطه على مستوى الجهاز (System-wide) — يؤثر على كل المستخدمين.

**4. أعد تشغيل التطبيق** — سيقرأ الملف من المسار الجديد مباشرةً.

### التحقق من نجاح التغيير

افتح CMD وأدخل:
```cmd
echo %SQLITE_DB_PATH%
```
يجب أن يظهر:
```
D:\SCVA-Data\scva-members.db
```

### ضبط صلاحيات المجلد (مهم)

افتح CMD كمسؤول وأدخل:
```cmd
icacls "D:\SCVA-Data" /grant Users:(OI)(CI)F /T
```
هذا يمنح كل مستخدمي الجهاز صلاحية كاملة على المجلد.

### ⚠️ تنبيهات مهمة

| الموضوع | التفاصيل |
|---|---|
| **صلاحيات الكتابة** | تأكد أن كل مستخدمي Windows لديهم صلاحية قراءة وكتابة على المجلد |
| **المستخدمون المتزامنون** | SQLite لا تدعم أكثر من مستخدم واحد يكتب في نفس الوقت — إذا فتح شخصان التطبيق معاً قد تحدث مشاكل |
| **مجلدات الشبكة** | لا تضع الملف على Network Drive — SQLite لا تعمل بشكل موثوق عبر الشبكة |

### التراجع والعودة للمسار الافتراضي

```cmd
:: احذف متغير البيئة (افتح CMD كمسؤول)
reg delete "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment" /v SQLITE_DB_PATH /f
```
ثم أعد تشغيل التطبيق — سيعود للمسار الافتراضي في `AppData`.
